# Identidad de marca — Sky Burger

## Identidad
- Marca: **Sky Burger**, hamburguesería artesanal con mascota «gato Sky».
- Eslogan propuesto: «Cada bocado cuenta una historia».
- Personalidad: cercana, creativa, juvenil, con énfasis en sabor artesanal.
- Voz: español rioplatense accesible, frases cortas y concretas.

## Paleta
| Token de uso | Valor | Función |
|---|---|---|
| Rojo principal | `#E63946` | CTA, selección, acento |
| Fondo oscuro | `#1D1D1D` | Identidad principal |
| Superficies | `#282828` (actual en CSS) | Tarjetas |
| Blanco | `#FFFFFF` | Texto, contraste |
| Beige | `#F8E9D2` | Calidez y detalles |

- Titulares: **Fredoka**; cuerpo: **Quicksand**.
- Logotipo y símbolo del gato Sky: variantes a documentar con los archivos originales que correspondan.

## Consistencia multimedia
Una imagen IA debe respetar la comida, la paleta y un personaje coherente; no insertar logotipos de marcas reales, personas identificables sin consentimiento ni afirmar que un local ficticio es real. Para banners fijos usar `public/marca/` o `public/media/`; para fotos variables del catálogo usar Supabase Storage.

## Declaración
Las piezas generadas con IA se etiquetan y documentan en `multimedia/FICHAS-IA.md`. No se puede deducir con certeza el prompt, modelo o licencia originales a partir del resultado final.
