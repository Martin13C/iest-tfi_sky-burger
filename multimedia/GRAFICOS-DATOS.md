# Plan de infografía SDD y tres gráficos verificables

No generar valores al azar. Los gráficos son para el informe/entregable, no la sección Estadísticas del sitio.

1. **Commits por semana:** fuente `git log` del repositorio; guardar extracción CSV y fecha de corte, verificar zona horaria/autor.
2. **Requisitos por estado:** fuente `specs/*/verificacion.md`, separar cumple/no cumple/pendiente; registrar total exacto.
3. **Multimedia generada y utilizada:** fuente `multimedia/FICHAS-IA.md` y carpeta de originales; registrar piezas generadas/rechazadas, si existe evidencia.
4. **Infografía ciclo SDD:** Constitución → Spec → Clarificación → Plan → Tareas → Implementación → Verificación → Cambio. Relacionar cada paso con archivos concretos.

## Entrega de cada gráfico
- Imagen SVG/PNG y fuente CSV/script o tabla reproducible.
- Título, unidad, período de corte y fuente verificable.
- Leyenda «Gráfico elaborado con ayuda de IA; datos extraídos de [fuente]» según herramienta real.

No mezclar estas gráficas académicas con visitas web de clientes; Umami no forma parte de v1.
